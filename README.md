# afifzuhdi.com

Personal portfolio of **Afif Zuhdi**, a back-end developer in Malaysia.

**Live:** https://www.afifzuhdi.com/

## Stack

- [Vite](https://vite.dev/) with plain HTML, CSS and JavaScript. No framework.
- Self-hosted fonts via Fontsource: Bricolage Grotesque, Hanken Grotesk, IBM Plex Mono.
- Structured data (JSON-LD `Person` / `ProfilePage`), Open Graph and Twitter cards, sitemap and robots.
- Respects `prefers-reduced-motion`. Content stays readable without JavaScript.

## Run locally

```bash
npm install
npm run dev       # http://127.0.0.1:5190
npm run build     # static output in dist/
npm run preview   # serve dist/ on http://127.0.0.1:5191
```

The build is fully static, so `dist/` can be served from any web host.
